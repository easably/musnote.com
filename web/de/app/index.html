Was die iOS-App ist

MusNote Voice (Arbeitstitel) ist die mobile Heimat unseres Live-Pitch-Stacks — dieselbe Idee wie die Voice-Tools auf der Website, für das Mikrofon in der Tasche.

  • Live-Pitch-Grafik — Kontur sehen, während Sie sprechen oder üben.
  • Note + Cents — Intonation in Echtzeit feinjustieren.
  • Aufnehmen & anhören — kurzer Take, sofort zurückhören.
  • Auf dem Gerät — der Kernspiegel braucht keinen Server.
Der öffentliche TestFlight-Link ist noch nicht hinterlegt. Sobald er live ist, wird der grüne Button oben zu Zur iOS-Beta und öffnet Apple TestFlight. Bis dahin nutzen Sie die Voice-Tools im Browser.
Öffentliches Testen ist über TestFlight freigeschaltet. Installation über den Button oben — kein App-Store-Eintrag nötig für die Beta. Feedback fließt in Language-Karaoke (Phrase + Pitch) und berufliches Sprechen.

So funktioniert der öffentliche Test

Auf dieser Seite erscheint der TestFlight-Public-Link. Sie brauchen ein iPhone und die kostenlose TestFlight-App von Apple. Offenes Android-Testing kommt später.

  • iOS — TestFlight-Public-Link (diese Seite).
  • Jetzt im Web — Shadow a phrase und weitere Tools unter Stimme.
  • Nicht in der Beta — ganzer Song → Notenblatt; schwere Audio-zu-Noten bleibt Server / Website.
