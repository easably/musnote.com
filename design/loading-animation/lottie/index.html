Волна превращается в ноты

Пока API читает запись: волна бежит, её гребни отрываются нотами и падают на клавиши (ля — до — ми). Цикл 3 с, бесконечный. Один файл musnote-loading.json играет и на сайте (lottie-web), и во Flutter (пакет lottie). Подписи — не в анимации, а в HTML / Flutter, чтобы переводились на 11 языков.

Как использовать

Сайтlottie_light.min.js (SVG-плеер без выражений, ~165 КБ, ~45 КБ gzip) + lottie.loadAnimation({container, renderer:'svg', loop:true, path:'/assets/anim/musnote-loading.json'}). JSON ~80 КБ (~9 КБ gzip). Грузить плеер лениво — только когда пошёл запрос к API.
FlutterПакет lottie (pub.dev) → Lottie.asset('assets/anim/musnote-loading.json', repeat: true). Подписи и таймер — обычные Text, строки из локализации.
ПравкаИсточник — build_lottie.py. Цвета он читает из design/tokens/musnote.tokens.json. python3 build_lottie.py пересобирает JSON.
Reduced motionВеб: prefers-reduced-motion → goToAndStop(110, true) (кадр с подсвеченной клавишей). Flutter: MediaQuery.disableAnimations → animate: false.
МинусСторонний плеер на вебе (+~45 КБ gzip) против своей реализации на canvas без зависимостей (план, часть 2). Зато один файл на обе платформы и правка без кода.
Подписи: «Слушаем запись…» → «Ищем ноты…» → «Раскладываем по клавишам…» раз в 3 с; через 20 с — «Длинная запись — ещё немного»; через 90 с — «Это дольше обычного». Время — сколько прошло, без процентов.
