# Анимация ожидания — формулы

Варианты A, B и C считаются по формулам ниже. Вариант D — готовый ролик `design/loading-animation/lottie/musnote-loading.json`; его собирает `build_lottie.py` из этих же токенов.

Числа из `design/tokens/musnote.tokens.json`, группа `animation.loading`. В CSS это `--animation-loading-*`.

| Токен | Значение |
|---|---|
| cycle | 4000 мс |
| height | 140 px |
| caption | 3000 мс |
| long-after | 20000 мс |
| slow-after | 90000 мс |
| amplitude | 18 px |
| wavelength | 160 px |

Время `t` — секунды с начала ожидания. `cycle` в формулах — 4 секунды.

## Волна

Центр по высоте кадра: `height / 2` = 70.

```
waveY(x, t) = 70 + 18 * sin(x / 160 * 2π − t / 4 * 2π)
```

Контрольные точки (совпадут у веба и Flutter, допуск 0,01):

| x | t | y |
|---|---|---|
| 0 | 0 | 70 |
| 40 | 0 | 88 |
| 0 | 1 | 52 |

## Вариант A · Волна → ноты

Волна бежит по формуле выше. Пять полосок. Фаза падения полоски `i` (0…4):

```
fall(t, i) = дробная часть(t / 4 + i * 0.17)
```

`fall = 0` — полоска у правого края волны (x = 88% ширины, y = waveY). `fall = 1` — она дошла до клавиатуры (нижние 28 px кадра). Цвета по кругу: `--c-r`, `--c-t`, `--c-f`. Клавиша под полоской вспыхивает, пока `fall > 0.82`.

Контроль: `fall(0, 0) = 0`, `fall(2, 0) = 0.5`, `fall(0, 1) = 0.17`.

## Вариант B · Ноты на волне

Пять кругов. Амплитуда волны здесь 14, длина волны 180 (только этот вариант; токен 18/160 остаётся у A).

```
x(t, i) = дробная часть(t / 4 + i / 5) * width
y = 70 + 14 * sin(x / 180 * 2π − t / 4 * 2π)
fade = sin(дробная часть(t / 4 + i / 5) * π)
```

При ширине 300 и `t = 0`, `i = 0`: x = 0, y = 70, fade = 0.

## Вариант C · Клавиши-эквалайзер

Семь полос, как иконка A (`design/app-icon/icon-a-eq-keys.svg`). Базовые доли высоты: `0.45, 0.72, 0.55, 0.90, 0.62, 0.80, 0.48`. Полосы 2 и 5 (с нуля) — `--c-t` и `--c-f`, остальные белые.

```
share(t, i) = base[i] * (0.75 + 0.25 * sin(t / 4 * 2π + i))
```

Контроль: `share(0, 0) = 0.45 * 0.75 = 0.3375`. `share(0, 2) = 0.55 * (0.75 + 0.25 * sin(2))`.

## Подписи

По кругу каждые 3 с: «Слушаем запись…», «Ищем ноты…», «Раскладываем по клавишам…». Рядом прошедшее время `м:сс`. Процентов нет.

С 20 с к фразе добавляется «Длинная запись — ещё немного». С 90 с — «Это дольше обычного».

`prefers-reduced-motion`: один кадр при `t = 0`, подписи и время остаются.
