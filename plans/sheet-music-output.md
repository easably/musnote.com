# Нотный стан в PDF, MusicXML и текст по тактам — исследование и предложение

Статус: черновик куратора (22.11). Исполнителю не передано, ждёт решения пользователя.

**Решение пользователя (22.11):** приложение пока бесплатное, поэтому лицензии «только некоммерческое использование» допустимы. Берём лучшее по качеству. Компоненты с такой лицензией помечены **NC**. Если появится платная версия, подписка или реклама, их придётся заменить. Перечень — в конце документа.

## Что отдаём сейчас
Сервер (Basic Pitch, после разделения Demucs) возвращает ноты как события: `midi, start, end (сек), velocity`. Такта, темпа, размера, тональности, длительностей (четверть, восьмая), разделения рук нет. Отсюда:
- PDF — «лист с буквами», а не нотный стан;
- TXT — сплошной список;
- MIDI — «исполнительский», без сетки тактов: в нотном редакторе превращается в кашу.

## Чего не хватает для нормальных нот
1. **Доли и такты** — найти доли и сильные доли в аудио.
2. **Квантование** — привязать начала и длительности нот к сетке долей, получить длительности (♩ ♪ …).
3. **Тональность, размер, написание** (C# или D♭), **руки или голоса**: пианино — два стана (правая/левая), голос — один стан, мелодия.
4. **Вёрстка** — MusicXML → SVG/PDF, плюс таблица «такт → секунды» для таймингов.

## Открытые библиотеки

| Шаг | Библиотека | Лицензия | Заметки |
|---|---|---|---|
| Доли и сильные доли | **Beat This!** (CPJKU, ISMIR 2024) | MIT (код и веса) | точнее старых; на том же GPU, что Demucs |

| Квантование, длительности, руки, тональность, размер | **PM2S** (Liu и др., ISMIR 2022) | проверить лицензию репозитория | ровно наша задача: исполнительский MIDI → MIDI-партитура с руками |
| Работа с партитурой, написание нот, голоса, экспорт MusicXML/MEI | **partitura** (CPJKU) | Apache-2.0 (проверить) | pitch spelling, тональность, разделение голосов |
| То же, запасной | **music21** (MIT) | BSD-3 | `quantize`, `makeNotation`, экспорт MusicXML |
| Вёрстка MusicXML → SVG/PDF | **Verovio** | LGPL-3 | колёсико для Python, без GUI; выдаёт **timemap** (такт ↔ мс) — тайминги в PDF и подсветка при проигрывании; есть привязки JS и Swift |
| Вёрстка (максимум качества) | MuseScore CLI `mscore -o x.pdf x.musicxml` | GPL-3 | тяжёлый (Qt, offscreen), на сервере допустимо |

GPL и LGPL на **сервере** нас не связывают: мы не распространяем код. В само приложение — только BSD/MIT (OSMD) или Verovio как отдельный JS в WebView.

## Предлагаемый конвейер (на сервере, после Basic Pitch)
`аудио → Demucs → Basic Pitch (ноты по дорожкам)` + `Beat This! (доли по миксу)` → **PM2S** или правила квантования на music21 (сетка 1/16, триоли по желанию) → **partitura / music21**: тональность, написание, пианино на 2 стана (руки из PM2S, иначе граница около C4), голос — 1 стан, монофония → **MusicXML** → **Verovio** → SVG → PDF (+ timemap JSON).

Новые поля ответа: `tempo_bpm`, `time_signature`, `key`, `beats: [сек]`, `downbeats: [сек]`, по дорожкам `musicxml` (или ссылка на файл задания), `measures: [{n, start, end}]`.

## Что получит пользователь
- **PDF «Ноты»** — настоящий нотный стан по дорожке; над каждой строкой время начала («0:12»); на титуле темп, размер, тональность. «Лист с буквами» оставить второй строкой для тех, кто не читает ноты.
- **MusicXML** — новая строка в «Забрать»: открывается в MuseScore, Sibelius, Flat, GarageBand.
- **MIDI** — квантованный, с темпом и тактами: в редакторе выглядит как ноты, а не каша. Исполнительский — по желанию.
- **TXT** — по тактам и строкам: `Такт 5 · 0:12.4 | П: C4 E4 G4 | Л: C3`. Пианино — руки раздельно, остальные дорожки — каждая отдельно.

## Порядок (предложение)
1. Прототип на server7 в `api/app/engines/score/` за параметром `engine=score` (единый API, план `one-api-web-parity.md`). Проверка на Capaldi и c-major-scale: такты совпадают с долями на слух, руки разделены разумно.
2. Вывод: MusicXML + PDF (Verovio) + timemap. Сравнить вёрстку Verovio и MuseScore на тех же файлах.
3. Клиенты: «Ноты (PDF)» и «MusicXML» в «Забрать»; квантованный MIDI; TXT по тактам. Сайт и приложение одновременно (паритет).
4. Позже: показ нот в приложении через OSMD с курсором в такт проигрыванию.

## Риски
- Квантование поп-музыки с рубато и свободным вокалом ошибается. Нужен ручной выбор темпа ×2 / ÷2 и честная подпись «ноты черновые».
- Демо-голос из Basic Pitch шумный: дрожание высоты → лишние короткие ноты. Нужна чистка мелодии (минимальная длительность, слияние соседних).
- Время: Beat This! + квантование + вёрстка добавят секунды к разбору. Это ещё одна фаза в «прогрессе разбора».
