# Audio → piano notes

Выбор: 2026-11-20. Свой расчёт в папке `api/` этого репозитория, свой Docker. Платный сервис не берём. Выкладка: push в `main` → GitHub Actions → server8, каталог из `DEPLOY_PATH` (сейчас `/home/admin2/deploy/musnote`). Сайт по-прежнему уезжает на Cloudflare Pages отдельным workflow.

## Схема для человека

1. Загружает запись.
2. Видит ноты на клавиатуре.
3. Нажимает «сыграть» и слышит их по очереди.
4. Рядом учебник аккордов: как эта фигура лежит на клавишах.

Шаги 3 и 4 уже есть (пианино и страницы аккордов). Шаг 2 — сервис `api/`: файл на `POST /v1/piano-notes`, в ответ список нот. Сайт его ещё не вызывает. Текст песни по-прежнему делает FreeDubbing, это другой инструмент.

## Что обещаем в поиске

Главная фраза США: **audio to piano notes**.

Рядом: audio to notes, song to piano notes, song to notes converter, audio to midi, song to midi, piano letter notes.

**Sheet music** (нотный лист, стан, PDF) не пишем, пока на экране только клавиатура.

## Где это живёт

| Шаг | Где |
|---|---|
| Файл → список нот (высота и время) | Папка `api/` в этом репозитории. Свой Docker (`api/docker-compose.yml`, порт 8095). Не FreeDubbing и не Cloudflare Pages |
| Клавиши и «сыграть» | Страница на musnote.com |
| Как сыграть фигуру | Уже собранные страницы аккордов. Это второй шаг, не заголовок сайта |

Голосовые инструменты остаются в меню `/tools/`.
