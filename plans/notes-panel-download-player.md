# Панель «аудио → ноты»: перетаскивание, плеер, скачивание

Решение 2026-11-20. Продолжает [audio-to-piano-notes.md](audio-to-piano-notes.md).

Сейчас человек получает ноты на клавиатуре и ничего не уносит с собой. У конкурентов (Bots for Music, Piano2Notes, Songscription) после транскрипции всегда есть скачивание: PDF, MIDI, MusicXML. Обычно оно платное или только на 20–30 секунд. Наш ответ: **MIDI и печатный лист с буквами нот, бесплатно и без регистрации**. Нотный стан (PDF sheet music, MusicXML) пока не обещаем.

## Что сейчас не так (по коду)

Панель: `web/index.html` (стр. 40–58), такая же на 11 языках и на `/<lang>/song-to-notes/`. Логика: [web/assets/js/page-audio-to-piano-notes.js](../web/assets/js/page-audio-to-piano-notes.js).

1. **Нет паузы и стопа.** `playTimeline()` расставляет `setTimeout` на все ноты сразу. Остановить можно только новым «Сыграть». Уже звучащие ноты при этом доигрывают.
2. **Длительность нот теряется.** API отдаёт `start`, `end`, `velocity`, а `MN.play()` играет каждую ноту фиксированные ~1,6 с. Короткие ноты гудят, долгие обрываются.
3. **Не видно, где мы в записи.** Нет прогресса, времени и перемотки.
4. **Нативный выбор файла.** На русской странице кнопка «Choose File / No file chosen» на английском (язык браузера). Перетащить файл нельзя.
5. **Два шага вместо одного.** Выбрал файл → ещё надо нажать «Получить ноты».
6. **Скачать нечего.** Basic Pitch в `api/app/notes.py` уже строит MIDI (`_midi`), но он выбрасывается.
7. **`clipped` игнорируется.** API режет до 4000 нот (`MAX_NOTES`), страница об этом не говорит.

## Что делаем

### 1. Загрузка: перетаскивание

- Вся карточка — зона сброса. При `dragover` пунктир становится изумрудным, фон `--mn-green-50`.
- Нативный `<input type="file">` визуально скрыт, вместо него кнопка «Выбрать файл» на языке страницы.
- Проверка до отправки: тип (те же расширения, что в `AUDIO_SUFFIXES` API), размер ≤ 15 МБ. Ошибка — в той же карточке, красным.
- **Транскрипция стартует сама** после выбора или перетаскивания. Кнопку «Получить ноты» убираем.
- После загрузки зона сворачивается в строку: имя файла, размер, «Другой файл».
- На телефоне — только кнопка (перетаскивания там нет), зона ниже по высоте.

### 2. Ожидание и итог

- Ожидание: полоска бегущего прогресса и «Читаем ноты…». Кнопки плеера и скачивания неактивны.
- Итог одной строкой: число нот, длительность (`max(end)`), диапазон (самая низкая — самая высокая нота).
- Если `clipped: true` — строка «Показаны первые 4000 нот». Обрезано, значит, MIDI тоже неполный: так и пишем.
- Клавиатура подстраивается под диапазон, как сейчас (`buildKeyboard`).

### 3. Плеер

- **Играть / Пауза** одной кнопкой, **Стоп** (в начало). Пробел — играть/пауза, когда фокус не в поле ввода.
- **Полоса прогресса** с перемоткой кликом и перетаскиванием, время `0:12 / 0:45`.
- **Скорость** 0,5× · 0,75× · 1× — для разучивания.
- Ноты звучат свою длительность `end − start`, громкость из `velocity`.
- Клавиша горит с `start` до `end` нотой, а не всем аккордом сразу. Цвет — `hl-r` (как сейчас).
- По концу — в начало, подсвечены все ноты записи (как сейчас после проигрывания).
- Реализация: часы на `AudioContext.currentTime`, планирование нот порциями на ~200 мс вперёд (lookahead), а не `setTimeout` на всю запись. Пауза = запомнить позицию + остановить все звучащие осцилляторы. Для этого нужен голос, который возвращает узел, — `voice()` сейчас в `chords-shared.js` внутренний. Добавить в общий файл экспорт, который возвращает `{stop()}`, не ломая `MN.play` для страниц аккордов.

### 4. Скачать — кнопка с меню

Главное действие — **MIDI**, остальное в выпадающем меню. Кнопка неактивна, пока нет нот.

| Пункт | Что получает человек | Как делаем |
|---|---|---|
| **MIDI-файл (.mid)** — по умолчанию | Открывается в GarageBand, MuseScore (там сразу нотный лист), Synthesia (падающие ноты) | В браузере из `notes`. Формат 0, одна дорожка, 480 тиков на четверть, темп 120 → 1 с = 960 тиков. Программа 0 (рояль). `velocity × 127`, от 1 до 127. Имя: `<имя-файла>-musnote.mid` |
| **Лист с буквами нот** | Страница для печати / «Сохранить как PDF» | Отдельный печатный вид (`@media print`) + `window.print()`. См. ниже |
| **Ноты текстом (.txt)** | `C4 E4 G4 …` построчно по фразам | Из `notes`, те же правила группировки, что у листа |
| **Скопировать ноты** | То же в буфер обмена | `navigator.clipboard.writeText`, подтверждение «Скопировано» |

**Почему MIDI в браузере, а не из API:** ноты с временем уже есть на странице, писатель MIDI — около 60 строк без библиотек, API и Docker менять не нужно, работает сразу на всех 11 языках. Вариант «отдавать `_midi` из API» оставляем на потом, если понадобится точность Basic Pitch (pitch bend).

**Лист с буквами нот** — наша изюминка, у конкурентов её нет:

- Шапка: имя файла, дата, `musnote.com`.
- Маленькая клавиатура-легенда с подписанными октавами (C3, C4, C5).
- Ноты подряд крупно, по фразам: пауза > 0,6 с → новая строка.
- Ноты, начавшиеся в пределах 40 мс, — аккорд: `[C E G]`.
- Переключатели перед печатью: с номером октавы / без; буквы / До-Ре-Ми (по умолчанию До-Ре-Ми на ru, es, pt, pl…, буквы на en, de, ja, ko, zh, vi — сверить с тем, как подписывают ноты в каждой стране).
- Цвет клавиш на легенде — как на сайте, но лист читается и в чёрно-белой печати.

- Остальные 9 языков — перевести с EN.

### 6. Тексты интерфейса

Все новые строки — в `data-msg-*` карточки, как сейчас, на 11 языках. Новые ключи: `drop`, `choose`, `limits`, `another`, `found` (с подстановкой числа, длительности, диапазона), `clipped`, `play`, `pause`, `stop`, `speed`, `download`, `dlMidi`, `dlSheet`, `dlTxt`, `copy`, `copied`, `badType`.

## Проверка

- MIDI: файл начинается с `MThd`, одна дорожка, число note-on = числу нот. Открыть в MuseScore или GarageBand (человек, в конце) — ноты и тайминг совпадают с клавиатурой на сайте.
- Плеер: пауза посреди аккорда глушит звук сразу; продолжение — с той же точки; перемотка на середину — звучит с середины; 0,5× вдвое длиннее; конец — сброс в начало.
- Перетаскивание: mp3 перетащен на карточку → транскрипция пошла без клика. Неверный тип и > 15 МБ — понятная ошибка, запрос не уходит.
- `clipped` на длинном файле видно в итоге.
- Печать листа: предпросмотр печати в Chrome и Safari, одна и несколько страниц, чёрно-белая печать читается.
- Телефон (iOS Safari, Android Chrome): выбор файла, плеер, скачивание MIDI.
- Все 11 языков: нет английских строк на неанглийских страницах.
- Страницы аккордов после правки `chords-shared.js` работают как раньше: звук, анимация прыжков, часы.
