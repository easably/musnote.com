# Flutter Ideas: аккорды и позиция голоса (только preview-экраны)

Идеи с сайта Musnote — **отдельные экраны для оценки**.  
Они **не смешиваются** с текущим Vocal Note Monitor (график / тюнер / record / settings).

## Как открыть

Меню монитора → **Ideas (preview)** → список прототипов.

Код: `vocal_note_monitor/lib/ideas/`

## Экраны

| # | Экран | Что оценивать |
|---|--------|----------------|
| 1 | Chord role | Роль ноты в выбранном аккорде (root / 3rd / 5th…) |
| 2 | Piano strip | Мини-клавиатура: тона аккорда + живой голос |
| 3 | Detect chord | Угадывание аккорда по недавним pitch-class |
| 4 | Progression | I–V–vi–IV с целевой ролью |
| 5 | Voice leading | Подсказка ближайшего тона к следующему аккорду |

## Правило

- Основной monitor / settings / pitch graph — без chord-логики.
- Идеи можно принимать / отклонять по экранам, не меняя текущий продукт.
