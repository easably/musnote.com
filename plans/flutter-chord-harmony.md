# Flutter: аккорды и позиция голоса

Идеи переноса с веб-сайта Musnote (piano + chord tutorial + статьи) в **Vocal Note Monitor**.

## Что уже есть на сайте

| Источник | Что умеет |
|----------|-----------|
| `piano.js` | Клавиатура, major-триады C–B, подсветка тонов аккорда |
| `chord-tutorial.js` | Major / minor / dominant 7, ноты с октавами, chips |
| Статьи | Римские цифры, прогрессии (I–V–vi–IV и др.), инверсии, voice leading — только текстом |
| `notes.json` | 88 клавиш, частоты, частично аккорды с интервалами |

Сайт показывает аккорд на клавиатуре, но **не анализирует голос** и не говорит, какую роль в аккорде поёт человек.

## Варианты улучшений для Flutter (по приоритету)

### 1. Текущий аккорд + роль ноты (MVP)

Пользователь выбирает аккорд (или гамму + ступень). При пении приложение показывает:

- ноту и cents (уже есть);
- **роль в аккорде**: root / 3rd / 5th / 7th / non-chord;
- цвет: chord tone vs проходящая нота.

Данные: аккорд как `root + intervals` (`[0,4,7]`, `[0,3,7]`, `[0,4,7,10]`…), не хардкод строк как на сайте.

### 2. Мини-клавиатура под графиком

Узкая piano-strip (как на сайте), подсветка:

- текущего голоса;
- тонов выбранного аккорда.

Связывает «что слышу» с «где на клавиатуре» — сильный мост с Musnote.

### 3. Распознавание аккорда из пения

Окно стабильных pitch-class за N секунд → матч к шаблонам (maj/min/7).  
Полезно, когда человек распевает арпеджио: «детектирован C major».

### 4. Прогрессии и позиция в гармонии

Режимы из статей: I–V–vi–IV, ii–V–I.  
На каждом аккорде — целевая роль (например, всегда 3я) и проверка попадания.

### 5. Voice leading coach

Между аккордами: ближайший тон следующего аккорда, подсказка «спустись на D».  
Из теории сайта, но интерактивно для вокалиста.

### 6. Инверсии / войсинг

«Ты поёшь 5ю над C/E (1я инверсия)» — статьи упоминают инверсии, на сайте UI нет.

## Рекомендуемый первый шаг

Сделать **(1) + (2)**: выбор аккорда в Settings/Scale, оверлей ролей на pitch graph + маленькая клавиатура.  
Это максимальный эффект при минимальной инвазивности к текущей архитектуре monitor screen.

## Модель данных (черновик)

```dart
class ChordTemplate {
  final String symbol;       // C, Am, G7
  final int rootPitchClass;  // 0..11
  final List<int> intervals; // [0,4,7]
}

class SungHarmonyAnalysis {
  final int midi;
  final double cents;
  final bool isChordTone;
  final String? role; // root, third, fifth, seventh
}
```

Не менять архитектуру pitch service радикально: поверх `PitchService.currentNote` добавить `HarmonyService(currentChord)`.
