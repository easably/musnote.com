# Мобильное приложение MusNote: один список записей

Решение пользователя 2026-11-21. Приложение пишем заново, **на Flutter-коде** (не FlutterFlow — см. «Критерии» ниже). Этот план — что строим. Код текущего `vocal_note_monitor/` берём как образец логики, а не как основу.

**Проект и идентификатор (решение пользователя 2026-11-21).**
- Приложение пишется в той же папке `vocal_note_monitor/`: код в `lib/` заменяется, проекты iOS и Android сохраняются.
- Идентификатор на всех платформах — **`com.musnote.vocalNoteMonitor`**.
  - iOS уже такой (App Store: «Audio to Piano Notes», Apple ID 6837194056).
  - Android сейчас `com.musnote.vocal_note_monitor` (`android/app/build.gradle*`, `applicationId`, `namespace`, путь `MainActivity`). Его меняем на `com.musnote.vocalNoteMonitor`.
  - Перед этим проверить, что в Google Play под старым ID ничего не загружено: после первой загрузки ID сменить нельзя. Если загружено — не менять, вопрос пользователю.
- Старые экраны остаются в истории git.

**Имя приложения (решение пользователя 2026-11-21).**
- **Системное имя** — то, что видно в магазинах и в поиске телефона: **`Audio to Piano Notes - MusNote`** (30 символов — ровно лимит App Store).
  - iOS: `CFBundleDisplayName` в `ios/Runner/Info.plist` (сейчас «Vocal Note Monitor»); имя карточки в App Store Connect меняет пользователь сам.
  - Android: `android:label` в `AndroidManifest.xml` (сейчас «Vocal Note Monitor»); `CFBundleName` / имя пакета не трогать.
  - Под иконкой на домашнем экране система сама сократит длинное имя (например «Audio to Pi…»). Это ожидаемо; поиск по телефону находит по полному имени.
- **Внутри приложения** заголовок главного списка — коротко **«MusNote»** (как в прототипе).

**Прототип:** [design/mobile-app/index.html](../design/mobile-app/index.html) — открыть с диска, всё кликается. Слева переключатели вариантов `V1–V5`, внизу строка «Ваш выбор для плана».

## Идея

Приложение — это **один список записей**. Каждая запись — звук, который человек добавил: записал, взял из файлов или из медиатеки. Из записи сервер делает ноты. Из нот — тренажёр с падающими нотами и файлы, которые можно забрать.

## Экраны

0. **Онбординг** — только при первом запуске. Показывает путь «звук → ноты и дорожки → клавиши и поделиться». Ролик — тот же `musnote-loading.json`, падающие ноты — та же геометрия. Вариант — `V6`.

1. **Список** (главный).
   - Шапка «MusNote», справа две иконки: **Инструменты** (своя иконка: сетка 2×2, в одной клетке нота) и **Настройки** (шестерёнка).
   - Записи от новых к старым: имя, источник, длительность, дата, статус — «Не обработано», «Читаем ноты…», «Ноты готовы».
   - Внизу справа — заметная круглая кнопка **«+»**.
   - Пустой список — подсказка «Нажмите „+“…».
2. **Диалог «+»** — источник звука:
   - **Запись** с микрофона;
   - **Файлы** (Files / iCloud / Google Drive);
   - ~~**Медиатека** телефона~~ — отменена пользователем 22.11 (коммит `487904a`): без запроса Apple Music и без CocoaPods.

   До 100 МБ, бесплатно. Файл копируется в хранилище приложения. Запись с микрофона сохраняется после «Стоп». После этого сразу открывается карточка новой записи.
3. **Запись** (диктофон): волна, таймер, кнопка «Стоп» — сохранить в список.
4. **Карточка записи** (портрет):
   - имя, источник, длительность, прослушать оригинал;
   - «Не обработано» → кнопка **«Получить ноты»**, обработка на сервере (`POST https://api.musnote.com/v1/piano-notes`, как на сайте);
   - пока ждём — ролик `musnote-loading.json` **240×96** (вдвое крупнее, чем на сайте, пропорция 400:160) и «Читаем ноты…» под ним;
   - «Ноты готовы» — страница простая:
     - строка итога по выбранной дорожке: «Найдено 38 нот · 0:16 · от C3 до G4»;
     - яркая кнопка **«Играть в тренажёре»** для выбранной дорожки;
     - список **«Дорожки»**;
     - список **«Забрать»**;
     - одна строка «Скоро: партитура (PDF) и MusicXML».
   - **Дорожки** — ответ сервера `POST /v1/separated-notes`: `vocals`, `piano`, `guitar`, `bass`, `other`, `drums`. У каждой — число нот и диапазон. Тихие (`empty: true`) — серые, «тихо — нот нет». Барабаны — «ударные — без нот». Выбрать можно только дорожку с нотами. По умолчанию выбрано пианино, если в нём есть ноты, иначе дорожка с наибольшим числом нот.
   - **Забрать** — список прямо на карточке (без отдельного листа):
     - над списком переключатель «<выбранная дорожка> / Все дорожки»;
     - строки: **MIDI-файл**, **Лист с буквами нот (PDF)**, **Ноты текстом (.txt)**, **Скопировать ноты**. MIDI для «все дорожки» — один файл, каждая дорожка своим треком. PDF — как печатный лист сайта (фразы, аккорды `[C E G]`, обозначения из настроек, без номера октавы; для «все дорожки» — раздел на дорожку);
     - **иконка справа в строке — «Поделиться»** (не «скачать»): открывает **стандартный системный лист** (iOS share sheet / Android Sharesheet) с файлом `<имя>[-<дорожка>]-musnote.<ext>`. Дальше человек сам решает: «Сохранить в Файлы», AirDrop, Telegram, Почта, GarageBand…;
     - **тап по самой строке — открыть файл**: отдельный экран просмотра со своей иконкой «Поделиться» в шапке. PDF и текст — системным просмотром (Quick Look на iOS, системный просмотрщик на Android). MIDI — встроенный плеер приложения (играть/пауза, прогресс) на синтезаторе приложения, одинаково на обеих системах;
     - **Android:** тап по иконке сначала показывает маленькое меню из двух пунктов — «Сохранить в Загрузки» (файл кладётся в общую папку Download, подтверждение «Сохранено: <имя>») и «Отправить…» (системный лист). На iPhone меню нет — сразу системный лист, где уже есть «Сохранить в Файлы» (решение пользователя 2026-11-21);
     - «Скопировать ноты» — только копирует текст, без иконки;
     - отдельной кнопки «Поделиться нотами» и иконки Share в шапке карточки нет.
5. **Тренажёр** — **альбомная ориентация, весь экран:**
   - падающие ноты на клавиатуру, клавиатура на всю ширину;
   - пауза, скорость 0,5 / 0,75 / 1×, прогресс, закрыть;
   - если телефон в портрете — экран «Поверните телефон» с кнопкой;
   - закрытие или поворот обратно в портрет → снова карточка записи.

   Геометрия — та же, что на сайте: `web/assets/js/falling-notes.js` (`rangeForMidis`, `keyLayout`, `barsAtTime`). Её Dart-копия — `vocal_note_monitor/lib/models/falling_notes.dart`.
6. **Инструменты** — все инструменты приложения и сайта (список ниже).
7. **Настройки** — только то, что есть:
   - **язык** — одна строка «Язык ›». По умолчанию «Как в системе» (язык ОС, не страна). Тот же лист — на онбординге (см. «Локализация»);
   - **обозначения нот** C D E / До Ре Ми (как переключатель на сайте);
   - «О приложении»:
     - **как это работает** — тот же онбординг, что при первом запуске. «Начать» возвращает в настройки. Сам первый запуск по-прежнему один раз;
     - **версия**;
     - **политика конфиденциальности** — ссылка на `https://musnote.com/privacy/`;
     - **написать нам** — `mailto:support@englishingames.com`.

   Не добавляем:
   - «где хранить» — выбора нет, записи на телефоне;
   - адрес сервера — пользователю не нужен;
   - скорость и звук тренажёра — они на самом экране тренажёра;
   - синхронизацию через аккаунт — не делаем.

   Настройки монитора голоса (порог громкости, калибровка A4, гамма, цвета — `lib/models/app_settings.dart`) остаются внутри инструмента «Монитор голоса».

## Что можно забрать

| В приложении сейчас | Скоро (не обещать как готовое) |
|---|---|
| MIDI-файл — GarageBand, MuseScore, Synthesia | Ноты на нотном стане (PDF-партитура) |
| Лист с буквами нот (PDF) | MusicXML |
| Ноты текстом (.txt) | |
| Скопировать ноты | |
| Дорожки по отдельности — сервер уже делит (`/v1/separated-notes`) | |

Лист с буквами (PDF) делается на телефоне. Логика MIDI, текста и листа — как в `web/assets/js/notes-export.js` и `renderSheet` в `web/assets/js/page-audio-to-piano-notes.js`. Файл уходит через системное «Поделиться» (Telegram, WhatsApp, Почта, «Сохранить в Файлы»).

## Инструменты

**Инструменты** (решение пользователя 22.11, возврат V5). В приложении остаётся монитор голоса. Плитки сайта открываются во встроенном окне: пианино, четыре страницы аккордов, четыре голосовых инструмента. У них маленькая метка «веб». «Аудио в ноты» отдельной плиткой нет — это главный список.

| Инструмент | Что открывает |
|---|---|
| Аудио в ноты | главный список записей |
| Монитор голоса | экран монитора (прежняя вкладка Voice) с его настройками |

Тренажёр — не отдельная плитка: он открывается из карточки записи. Инструмент сайта появляется здесь, только когда его перенесли в приложение отдельной задачей. Нижней панели вкладок (Voice / Notes / Settings) больше нет.

## Локализация (решение пользователя 2026-11-21)

- Исходный язык приложения — **английский**. Все строки интерфейса — через `flutter gen-l10n` (`flutter_localizations`, `intl`, файлы `lib/l10n/app_<код>.arb`). Строк в коде нет.
- Языки: **en, ru, es, de, fr, it, pl**.
- **Язык по умолчанию — язык системы, иначе English.** Берётся первый язык из `PlatformDispatcher.locales`, который есть в приложении (en, ru, es, de, fr, it, pl). Страна устройства на язык не влияет. На iOS язык, выбранный для самого приложения в Настройках, приходит первым в этом списке.
- **В Настройках — одна строка «Язык».** Значение: «Как в системе (Русский)» или эндоним выбранного языка. Нажатие открывает тот же лист, что кнопка языка на онбординге: «Как в системе» и семь языков. Выбор хранится на телефоне и применяется сразу, без перезапуска.
- Обозначения нот по умолчанию следуют языку: До Ре Ми для ru, es, fr, it, pl; C D E для en и de. Отдельный переключатель «Обозначения нот» в настройках остаётся.
- Переводят агенты по английскому исходнику. Русский пользователь проверил (2026-11-21) — в порядке; остальные — по желанию.
- Ролик и иконки без текста. Имя приложения в сторах пока одно, английское — `Audio to Piano Notes - MusNote`.

### Техническое задание по выбранным вариантам

**V1 · Главный список — карточки.**
- Вертикальный список карточек, от новых к старым. Отступ между карточками 12, радиус 20 (`radiusLg`), белый фон, тонкая рамка `line`, мягкая тень `shadowSoft`.
- Верх карточки: иконка источника (запись / файл / медиатека) в квадрате 42×42 на `green50`, имя (одна строка, обрезка с «…»), строка «Источник · длительность · дата», справа — статус-чип:
  - «Не обработано» — серый;
  - «Читаем ноты…» — янтарный;
  - «Ноты готовы» — зелёный.
- Низ карточки:
  - ноты готовы — миниатюра нот высотой 54 (полоски нот по времени и высоте, дорожка по умолчанию);
  - не обработано — пунктирная плашка «Нажмите, чтобы получить ноты».
- Тап по карточке открывает карточку записи. Удаление — свайп влево с подтверждением.
- Над списком — строка «N записей · хранятся на телефоне». Пустой список — иконка пианино, «Пока пусто» и подсказка про «+».
- Круглая кнопка «+» 66×66, `green500`, справа внизу, над системной полосой.

**V2 · Диалог «+» — нижний лист с вкладками.**
- Нижний лист со скруглением 28 сверху и «ручкой», затемнение фона. Закрытие — свайп вниз или тап по затемнению.
- Заголовок «Добавить звук», под ним «mp3, wav, m4a, flac · до 100 МБ · ✓ бесплатно».
- Три вкладки-сегмента (как переключатель на сайте):
  1. **Запись** — большая красная кнопка микрофона 96×96, по тапу открывается экран диктофона: волна, таймер, «Стоп» → запись сохраняется в список и открывается её карточка.
  2. **Файлы** — пунктирная зона «Выбрать файл» и кнопка «Открыть „Файлы“» (системный выбор файла: Files, iCloud, Google Drive).
  3. **Медиатека** — список аудио с телефона: имя, длительность. Тап — добавить. Под списком серая подсказка: «Песни из Apple Music защищены и не открываются. Подойдут ваши аудиофайлы и купленные треки без защиты.» *(Отменено пользователем 22.11, коммит `487904a`: медиатеки нет — без запроса Apple Music и без CocoaPods. Источники — «Запись» и «Файлы».)*
- Внизу листа, под вкладками — блок **«Нужен другой источник?»**: «Скажите, откуда вы хотите брать музыку — добавим самое частое» и чипы: YouTube-ссылка · Видео из галереи · Другое… (Spotify и Apple Music не предлагаем — обеспечить их не сможем, пользователь 2026-11-21)
  - Тап по чипу открывает почту на `support@englishingames.com` с темой «MusNote: хочу источник — <чип>» и телом с версией приложения и системы. Человеку остаётся нажать «Отправить».
  - Сервера и счётчиков не делаем — просьбы приходят письмами.
  - Это сбор пожеланий, а не обещание: ссылки YouTube в план не входят.
- Неверный тип или файл больше 100 МБ — ошибка в листе, запись не создаётся.
- Выбранный файл копируется в хранилище приложения, затем открывается карточка новой записи со статусом «Не обработано».

**V3 · Кнопка тренажёра — большая плашка.**
- На карточке записи со статусом «Ноты готовы», сразу под строкой итога и над списком дорожек.
- Во всю ширину, высота ~86, радиус 22, градиент `green400 → green700`, тень `shadowLift`. Слева иконка пианино 54×54 на полупрозрачном белом. Текст: «Играть в тренажёре», вторая строка «<Дорожка> · падающие ноты · поверните телефон».
- Играет выбранную дорожку. Если у записи ни в одной дорожке нет нот — плашки нет, вместо неё строка «Нот не нашлось».

**V4 · Экран тренажёра — чистый экран.**
- Только альбомная ориентация, весь экран, системные панели скрыты. Если телефон в портрете — экран «Поверните телефон» с кнопкой «Повернуть» (принудительно в альбомную).
- По умолчанию видны только падающие ноты и клавиатура на всю ширину. Геометрия — `falling-notes.js` / `falling_notes.dart` (`rangeForMidis` с минимумом 15 белых клавиш, `keyLayout`, `barsAtTime`, просмотр вперёд ~2,6 с). Клавиатура — нижние ~28 % высоты, звучащая клавиша подсвечивается, на полосках нот — буквы.
- **Тап по экрану** — на 3,5 с показывается панель сверху: закрыть ✕, название «Дорожка · запись», скорость 0,5 / 0,75 / 1×, пауза/играть, полоса прогресса. Второй тап или 3,5 с без действий — панель прячется. При первом входе 2,5 с видна подсказка «Тап — пауза, скорость, выход».
- Звук нот при начале каждой ноты. По концу — повтор с начала.
- ✕, системное «назад» или поворот в портрет → возврат на карточку записи в портретной ориентации.

**V5 · Инструменты — плитки 2×N.**
- Экран «Инструменты» открывается иконкой в шапке главного списка (слева от шестерёнки).
- Плитки по две в ряд на телефоне, три от ширины 700, четыре от 1000. Радиус 20. Группы: «В приложении», «Аккорды», «Голос». У плиток сайта метка «веб».
- Состав — таблица в блоке 22.11 (монитор и девять страниц сайта).


**V6 · Онбординг — четыре экрана** (первый прежний, за ним три из прототипа, 22.11).
- Только при первом запуске. Флаг «показан» хранится на телефоне.
- 1. «Из звука — в ноты на клавишах». 2. «Запишите мелодию или выберите файл». 3. «Мы находим ноты и делим на дорожки». 4. «Играйте вместе и забирайте ноты». Четыре точки, «Далее» / «Начать», «Пропустить», свайп. Тексты черновые, правка после просмотра.

## Порядок работ приложения (после этапа 0)

1. Хранилище записей на телефоне: файл + метаданные (имя, источник, длительность, дата, статус, ноты).
2. Добавление: запись (`record`), файлы (`file_picker`). Лимит 100 МБ. Медиатека отменена пользователем 22.11 (коммит `487904a`).
3. Карточка: запрос к `/v1/separated-notes`, ролик ожидания (разбор с разделением идёт 30–70 с), статусы, повтор при ошибке сети, список дорожек.
4. Тренажёр: альбомная ориентация только на этом экране, весь экран, геометрия падающих нот из общего файла, звук нот.
5. «Забрать» на карточке: переключатель дорожка/все; MIDI (все дорожки — один файл, несколько треков), лист с буквами (PDF), текст; иконка — системное «Поделиться», тап по строке — экран просмотра (PDF/текст — системный просмотр, MIDI — встроенный плеер); копирование.
6. Онбординг первого запуска (V6), флаг «уже показан» хранится на телефоне.
7. Инструменты (V5), настройки из двух пунктов, иконки шапки.
8. Строки интерфейса пока на одном языке. Локализацию добавим отдельной задачей.

## FlutterFlow или Flutter-код — критерии

**Выбран Flutter-код (пользователь, 2026-11-21).** Цены — с сайта FlutterFlow, проверены 2026-11-21.

| Критерий | FlutterFlow | Flutter-код |
|---|---|---|
| Простые экраны (список, лист, карточка, настройки) | быстро, мышкой | чуть дольше, но экранов мало |
| Тренажёр падающих нот, запись звука, принудительная альбомная ориентация, MIDI, монитор голоса | всё равно пишется кодом как Custom Widget / Action в редакторе FlutterFlow | обычный код. Уже есть `falling_notes.dart`, `musnote_tokens.g.dart`, монитор голоса, синтезатор нот |
| Работа с агентами (Cursor, Claude) по планам в git | проект живёт в облаке FlutterFlow. Агенты его не правят. «Push to GitHub» — односторонний, FlutterFlow перезаписывает ветку | агенты правят код и проверяют его, как сейчас с сайтом |
| Стиль из `musnote.tokens.json` | цвета и шрифты вручную в Theme Settings | подключается сгенерированный файл |
| Lottie-ролик | встроенный виджет | пакет `lottie`, одна строка |
| Цена | Basic $39/мес (выгрузка кода, публикация), Push to GitHub — с Growth ($80/мес за место) | бесплатно |
| Публикация в сторы | кнопкой из FlutterFlow | через Xcode / Gradle или Fastlane |

**Почему Flutter-код.** Главная ценность приложения — нестандартные части: тренажёр, запись, MIDI, дорожки. Их во FlutterFlow всё равно пришлось бы писать кодом. А агенты, которые уже работают в этом репозитории, проект во FlutterFlow править не могут. FlutterFlow имеет смысл, если экраны будет собирать мышкой человек без кода, а тренажёр и запись подключат готовыми кусками.
