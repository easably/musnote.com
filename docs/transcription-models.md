# Модели «аудио → ноты»

Сейчас в `api/` стоит Basic Pitch. Дальше по интересу — MuScriptor: несколько инструментов и нотный лист. Её веса нельзя использовать в коммерческом продукте.

Цифры видеопамяти: у MuScriptor large это чужой замер (одна песня, около 7 ГБ). У остальных авторы цифру карты не публикуют, в таблице — по размеру весов и по тому, как они сами советуют запускать.

| | Basic Pitch | Transkun | YourMT3+ | MuScriptor |
|---|---|---|---|---|
| Чья | Spotify | Yujia Yan | открытая, mimbres | Kyutai и Mirelo |
| Лицензия | Apache 2.0, можно в продукт | MIT, можно в продукт | GPL-3.0, жёстче: код рядом с ней тоже открывается | Код MIT. Веса CC BY-NC 4.0: только некоммерческое |
| Что слышит | Соло: пианино, гитара, мелодия | Только соло пианино | Несколько партий: пианино, струнные, ударные, голос | До ~36 инструментов, можно назвать какие ждать |
| Размер | мини-модель TFLite | веса около 50 МБ | 46 млн параметров | small 103 млн, medium 307 млн, large 1,4 млрд |
| Видеокарта | не нужна | не нужна, карта только ускоряет | не нужна, есть запуск на процессоре. На карте хватит 4 ГБ | small и medium — процессор. large — около 7 ГБ на одну песню, спокойно от 12 ГБ |
| Ответ | список нот, MIDI | MIDI | MIDI, партии отдельно | MIDI, MusicXML, PDF по инструментам, табы |
| Нотный лист | нет | нет | нет | да, если рядом установлен MuseScore 4 |
| Где мы | уже в `api/` | нет | нет | интересна, в продукт не встаёт из-за лицензии весов |
