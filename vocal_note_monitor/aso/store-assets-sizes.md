# App Store: какие промо-материалы бывают и какие размеры

Тексты на кадрах — [promo-screens-brief.md](promo-screens-brief.md). Здесь только **типы ассетов и пиксели**, чтобы генерировать контент без угадывания.

Официально: [Screenshot specs](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), [App Preview specs](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications), [Creative assets specs](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications).

## Карта мест (куда что светится)

| Место | Что видит человек | Ассет |
|---|---|---|
| Иконка в поиске / на карточке | Квадрат приложения | App Icon 1024×1024 |
| Строка поиска App Store | Иконка + имя + subtitle + **первый превью/скрин** | App Preview или Screenshot #1 |
| **Search results creative** (новый баннер в выдаче) | Широкая картинка или короткое видео **3:2** рядом с результатом | Creative: Search results |
| Карточка приложения (product page) | **Шапка** сверху страницы | Creative: Product page header |
| Карусель на карточке | До 3 роликов + до 10 скринов | App Preview + Screenshots |
| События в приложении | Карточка события | In-App Event (если будем делать) |

«Футер» в быту часто = низ кадра на скрине (наша оговорка про соло). В самом App Store отдельного «футер-ассета» нет: низ — это часть скрина / превью. Баннер **в поиске** — это Search results creative, не футер.

## 1. App Icon

| | |
|---|---|
| Размер | **1024 × 1024** px |
| Формат | PNG или JPEG, без прозрачности |
| Где | Иконка приложения в Xcode / ASC |

На иконке не писать длинный slogan. Имя уже в metadata: `Audio to Piano Notes`.

---

## 2. Screenshots (стандартные промо-картинки)

- До **10** штук на размер устройства.
- Формат: `.png` / `.jpg` / `.jpeg`, **без alpha**.
- Обязательно для сдачи сейчас: хотя бы один скрин для **iPhone Dynamic Island (medium display)**; Apple масштабирует на меньшие, если UI одинаковый.
- Первые 1–3 кадра попадают в поиск, если нет App Preview — делать их самыми сильными + оговорка ([promo-screens-brief.md](promo-screens-brief.md)).

### iPhone — приоритетные размеры (portrait)

| Группа | Типичные устройства | Portrait (px) |
|---|---|---|
| Dynamic Island large | 16 Pro Max, 15 Pro Max, 15 Plus… | **1320 × 2868** или 1290 × 2796 или 1260 × 2736 |
| Face ID large (если нет large DI) | 14 Plus, 13 Pro Max… | **1284 × 2778** или 1242 × 2688 |
| Dynamic Island / Face ID medium (обязательный минимум) | 14, 13, 12… | см. [screenshot specs](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) — Apple принимает набор размеров этой группы |

Практичный минимум для генерации контента сейчас:

1. **1320 × 2868** (large)  
2. **1290 × 2796** (часто используют как «6.7"»)  

Landscape — только если реально нужен; для нашего вертикального UI достаточно portrait.

### iPad

Нужен, **если** приложение поддерживает iPadOS: минимум скрин для **13" iPad**. Если iPhone-only — iPad-скрины не обязательны.

## 3. App Preview (ролик на карточке и в поиске)

| | |
|---|---|
| Длина | **15–30 секунд** |
| Сколько | До **3** роликов на язык и на размер устройства |
| Файл | до 500 MB; `.mov` / `.m4v` / `.mp4` |
| Кадры | до **30 fps** |
| Звук | Стерео AAC; на странице часто **сначала без звука** (autoplay mute) — текст на экране обязателен |
| Poster frame | По умолчанию ~5-я секунда; выбрать кадр, который читается без видео |

### Принятые разрешения превью (не путать с нативным экраном телефона)

| Ориентация | Accepted resolution |
|---|---|
| Portrait | **886 × 1920** |
| Landscape | **1920 × 886** |

Эти размеры Apple принимает для современных iPhone (19.5:9). Для генерации ролика целиться в **886×1920**, 15–30 с, H.264 ~10–12 Mbps.

Сценарий ролика (коротко): 0–3 с микрофон или MP3 → клавиши → «Play» → 1 строка оговорки про соло → конец. Без PDF sheet music.

## 4. Creative assets (новые: шапка страницы и баннер в поиске)

Это то, что часто имеют в виду под «картинка в поиске» и «широкая шапка», отдельно от обычных скринов.

### Product page header (шапка карточки приложения)

| | Image | Video |
|---|---|---|
| Соотношение | **21:9** | 21:9 |
| Разрешение | **3840 × 1646** | 3840 × 1646 |
| Длина видео | — | **5–30 с**, 30 или 60 fps |
| Safe area (важное в центре) | art safe ~**1646 × 661** со смещением (x≈1097, y≈493) | то же |
| Формат | **PNG** (без alpha) | `.mov` / `.m4v` / `.mp4` |

На шапке: бренд / «Audio to Piano Notes» + намёк на клавиши. Мелкую оговорку про соло можно, но не мельчить: safe area узкая.

### Search results (баннер в выдаче поиска)

| | Image | Video |
|---|---|---|
| Соотношение | **3:2** | 3:2 |
| Разрешение | мин. **1920 × 1280**, макс. **3840 × 2560** | то же |
| Длина видео | — | **5–30 с**, 30 или 60 fps |
| Формат | JPEG / PNG | `.mov` / `.m4v` / `.mp4` |
| Звук | — | в поиске видео **всегда mute** |

Практичный размер для генерации: **1920 × 1280** (или 2880 × 1920 для запаса резкости).  
Крупно: вход (mic / MP3) + клавиши. Оговорка — одна короткая строка.

Видео в поиске и на шапке **зацикливаются**.

## 5. Что генерировать в первую очередь (чеклист)

| # | Ассет | Размер / длина | Приоритет |
|---|---|---|---|
| 1 | Icon | 1024×1024 | обязательно |
| 2 | Screenshots (5 кадров из brief) | 1320×2868 (+ при желании 1290×2796) | обязательно |
| 3 | App Preview ×1 | 886×1920, **15–30 с** | желательно |
| 4 | Search results image | 1920×1280 (3:2) | желательно (видимость в поиске) |
| 5 | Product page header image | 3840×1646 (21:9) | желательно |
| 6 | Search / header video | 5–30 с, те же соотношения | опционально |
| 7 | Локали RU (+ DE) для скринов и creative | те же размеры | после EN |
