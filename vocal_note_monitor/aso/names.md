# App Store name, subtitle, keywords

Два слоя имени:

- **Система / магазин:** поисковая фраза языка + ` - MusNote` (EN: `Audio to Piano Notes - MusNote`).
- **Внутри приложения** (шапка списка файлов): коротко **MusNote**.

Фразы — как ищут на языке, не перевод EN: [search-phrases.md](search-phrases.md).

Лимиты Apple: name ≤ 30, subtitle ≤ 30, keywords ≤ 100 (через запятую, без пробелов после запятой). Слова из name/subtitle в keywords не повторять.
