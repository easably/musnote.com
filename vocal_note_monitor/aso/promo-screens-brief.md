# Задание: тексты на промо (скриншоты, шапка, подвал)

Зачем: имя в магазине ловит запрос **Audio to Piano Notes** / song / mp3. На картинках нельзя обещать «любой хит идеально ляжет на ноты». Иначе трафик будет, отзывы — «не работает».

Опора: SEO-ядро ([plans/tz-keyword-core-locales.md](../../plans/tz-keyword-core-locales.md)), имена ASO ([names.md](names.md)), продукт ([plans/audio-to-piano-notes.md](../../plans/audio-to-piano-notes.md)).

Пиксели и типы ассетов (скрины, ролики, баннер в поиске, шапка страницы): [store-assets-sizes.md](store-assets-sizes.md). «Подвал» ниже — текст на кадре, не отдельный файл App Store.

## Одно правило для всех картинок

На **каждом** промо-экране (App Store / Play / сайт / сторис) видно три слоя:

1. **Шапка** — что это за вход (микрофон или файл песни).
2. **Середина** — что человек видит (клавиши / ноты), без нотного листа PDF.
3. **Подвал** — короткая оговорка про соло.

Оговорка **обязательна**, если на кадре есть слово song, mp3, audio или «песня». Без оговорки такой кадр не сдаём.

## Подвал (footer) — одна фраза

Смысл на всех языках один. EN для en-US и запасной эталон:

| Язык | Текст подвала (коротко) |
|---|---|
| EN | Works best on a solo or clear melody. Full songs may be rough. |
| RU | Лучше соло или ясная мелодия. Целая песня может разобраться грубо. |
| DE | Am besten Solo oder klare Melodie. Ganze Songs können grob sein. |
| PL | Najlepiej solo lub wyraźna melodia. Cała piosenka może wyjść zgrubnie. |
| ES | Mejor un solo o melodía clara. Una canción completa puede salir tosca. |
| PT-BR | Melhor solo ou melodia clara. Música completa pode ficar grosseira. |
| JA | ソロやはっきりしたメロディ向き。曲全体は荒く出ることがあります。 |
| KO | 솔로·또렷한 멜로디에 잘 맞습니다. 노래 전체는 거칠 수 있어요. |
| ZH-Hant | 較適合獨奏或清楚旋律。整首歌可能較粗。 |
| ZH-Hans | 更适合独奏或清晰旋律。整首歌可能较粗。 |
| VI | Tốt nhất với solo hoặc giai điệu rõ. Cả bài có thể ra thô. |

На картинке подвал — одна строка мелким, но читаемым шрифтом. Не прятать в угол контрастом «в ноль».

## Шапка (header) — по типу кадра

Два разрешённых входа. Не смешивать обещания на одном кадре без подписи.

| Тип кадра | Шапка EN | Смысл |
|---|---|---|
| A. Микрофон | Sing or play — see notes live | Напел / сыграл → высоты / ноты на экране |
| B. Файл | Song or MP3 → piano notes | Загрузил запись → ноты на клавишах |
| C. После результата | Keys light up. Hit play. | Клавиши загорелись, можно сыграть |

RU для тех же типов:  
A `Спой или сыграй — ноты на экране`  
B `Песня или MP3 → ноты на клавишах`  
C `Клавиши загораются. Нажми «сыграть».`

## Набор кадров (минимум для магазина)

Порядок в карусели App Store / Play:

1. **Герой** — шапка B + клавиатура с нотами + подвал-оговорка.  
   Не писать на герое «any hit» / «perfect sheet music».
2. **Микрофон** — шапка A + живой контур / клавиши + подвал короче можно: `Solo and melody work best.`
3. **Файл** — шапка B + кнопка загрузки / mp3 + подвал полной оговоркой.
4. **Практика** — аккорды / «сыграть» как второй шаг. Без оговорки про соло, если на кадре нет song/mp3. Заголовок: `Then practise the chords` / `Потом потренируй аккорды`.
5. **Честно** (опционально, но желательно) — один кадр только про ожидание:  
   EN `Full band mixes are harder. Start with a solo line.`  
   RU `Полный микс с ударными сложнее. Начни с одной мелодии.`

## Нельзя на промо

- sheet music, PDF, пятилинейный стан как главный результат.
- «AI removes your accent», karaoke party, «any song perfect».
- Имя приложения без оговорки рядом, если крупно написано Song / MP3 / песня.
- Скрин «хит из топа → идеальные ноты» без подвала.

## Критерий «готово»

- У каждого локализованного набора скринов есть шапка + подвал по таблице.
- Хотя бы на одном из первых трёх кадров оговорка про соло читается без зума.
- Тексты совпадают с name/subtitle из [names.md](names.md) по смыслу, но не копируют keyword-спам на картинку.

## Кому и что сдать

Исполнитель (дизайн / сборка скринов): макеты EN + RU (+ DE если уже в магазине) с реальными строками из этого файла.  
Куратор: проверить, что ни один кадр с song/mp3 не ушёл без подвала.
